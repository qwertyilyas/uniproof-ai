# Статус реализации UNIPROOF AI MVP

Обновлено: 30 октября 2026

## Реализовано на публичном статическом сайте GitHub Pages

- Адаптивный сайт с модулями Document Verify и Skill Verify.
- Document Verify: локальная в браузере проверка расширения, размера, сигнатуры файла, базовой информации об изображении и ограниченного фрагмента PDF. Файл не отправляется на сервер.
- Skill Verify: форма проекта с ролью студента, описанием, выбранными навыками и доказательствами.
- Создание черновика Skill Proof Card.
- Локальное портфолио проектов с комментариями и демонстрационными действиями «подтвердить / отклонить / снять статус».
- Профиль студента, печать карточки/профиля и экспорт портфолио в JSON.
- Локальная форма обратной связи.
- Управление удалением локальных данных.
- README описывает доступные функции и ограничения.

## Принципиальные ограничения текущей версии

- GitHub Pages обслуживает только статические файлы. FastAPI из папки app/ отдельно не развёрнут и сайт с ним пока не соединён.
- Данные проектов, профиля и отзывов хранятся только в localStorage браузера. Они не синхронизируются между пользователями и устройствами.
- Действия преподавателя являются демонстрацией интерфейса. Нет аутентификации преподавателя, аудита и реального подтверждения.
- Нет AI inference для анализа навыков, OCR, устойчивого извлечения реквизитов, официальной проверки через EPVO / Smart Bridge.
- Проверка файла в браузере является технической подсказкой и не устанавливает подлинность.
- Google Forms / Sheets скрипт подготовлен, но форма ещё не создана в аккаунте владельца и не встроена.

## FastAPI prototype

- GET /api/health
- GET /api/official-verification/status
- POST /api/analyze
- Базовые тесты API находятся в tests/test_api.py.
- API не развёрнут на публичном сервере.

## Следующие обязательные этапы перед реальным запуском

1. Развернуть FastAPI на сервере и подключить HTTPS.
2. Добавить авторизацию, роли студента / преподавателя / работодателя, согласия и аудит.
3. Добавить OCR и надёжное извлечение полей.
4. Получить официальные доступы и документацию EPVO / Smart Bridge; не угадывать API.
5. Реализовать AI-подсказки навыков с выдержками из работы, рубрикой и неопределённостью.
6. Добавить реальное подтверждение преподавателем и историю изменений.
7. Добавить безопасные публичные ссылки на карточки, отзыв доступа и правила хранения/удаления данных.
8. Подключить настоящую Google Form и связанную Google Sheet.
